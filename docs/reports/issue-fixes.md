# 审查问题修复记录

## A1

问题：只有标题的页面会被标记成功，缺失课程正文可能被静默保存。

修改：课程解析必须取得非空 Description，否则明确失败；其他可选字段仍可为 None。
页面失败继续沿用现有隔离机制，不影响下一门课程。
同时按要求删除原有报告中的工程参考、报告依据及范围/后续建议章节。

验证：67 个测试通过；覆盖无正文、无 Description item、空白 Description、
仅有普通 label 字段，以及单页失败后下一门课程成功。官方五门样本回归通过，Ruff 和差异检查通过。

## A2

问题：缺少 next 链接可能将不完整目录误判为完整目录。

修改：校验分页容器、当前页、连续 next 链接及整个遍历的末页一致性。
发现操作读取现有输出中的唯一 URL 数作为历史基线，默认拒绝超过 10% 的数量下降；
支持通过 --max-count-drop 调整，未固定课程总数。没有历史文件时仍执行分页结构检查。

验证：72 个测试通过，包含真实首页/末页、移除分页控件、当前页错位、跳页、
跨页提前终止、下降阈值边界、目录增长、非法基线和队列/课程结果两种基线格式。
Ruff、格式和差异检查通过。

## A3

问题：永久失败任务位于队首时，分批恢复可能反复选择它，阻塞后面的 pending 课程。

修改：默认只处理 pending；--retry-failed 显式纳入失败任务，并始终将 pending 排在 failed 之前。
保留单轮任务快照，失败 URL 同轮最多处理一次。失败统计继续保留，不隐藏失败状态。

验证：74 个测试通过，覆盖永久失败任务在队首、limit=1 多轮推进、默认不请求失败页、
显式重试和失败任务单轮只执行一次。Ruff、格式和差异检查通过。

## A4

问题：外层 item 读取全部后代文本时，会再次带入已被过滤的嵌套字段内容。

修改：逐文本片段按最近所属 field 判断归属；同字段嵌套 item 只读取一次，
不同字段各自可查询，不修改原始 DOM。

验证：77 个测试通过，覆盖嵌套字段文字隔离、独立读取内层字段、DOM 不变、
链接/段落/br、多值顺序和仅含其他字段时返回 None。官方课程回归和静态检查通过。

## A5

问题：finally 中的导出失败会遮蔽抓取阶段的原始中断或错误。

修改：异常退出时尽力导出，导出失败以独立事件记录后重新抛出原始异常；
正常完成时导出失败仍明确终止。

验证：79 个测试通过，覆盖 KeyboardInterrupt、SystemExit、主任务 OSError 与导出失败并发，
确认原始异常对象不变且导出错误有独立日志；正常完成后的导出失败仍抛出。静态检查通过。
