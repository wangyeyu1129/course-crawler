# 数据管理与工程改进记录

## C1

改动：resume/discover/refresh 三种采集操作分离；发现仅入队、不抓详情，刷新仅处理已知队列。
空队列的恢复保留首次自动发现，空队列刷新明确报错；--refresh 保留为兼容别名。
验证：118 个测试通过，覆盖新增任务不影响成功任务、发现不抓详情、刷新不重新发现及空队列刷新。

## C2

改动：新增独立运行元数据，包含唯一 run ID、UTC 起止时间、Git revision、parser 源码哈希、
操作、状态、统计、完整性及快照哈希。开始写 running，正常/异常结束原子更新最终状态。
异常期间元数据写入失败独立记录，不遮蔽原始错误；课程 JSON 数组不变。
验证：119 个测试通过，新增多次运行身份、统计、时间及快照关联测试；既有中断和导出失败回归通过。

## C3

改动：正式输出仅在非空队列全部 succeeded 时发布；分批、失败或中断结果导出到 progress/。
运行元数据与 CLI 统计记录 published 和 export_path，快照关联实际导出文件。
验证：120 个测试通过，覆盖不完整运行保留原完整文件、进度可检查、完成后发布及中断进度保存。

## C4

改动：详情页解析前保存 UTF-8 HTML 输入，内容寻址去重；索引关联 URL、run ID、捕获时间与哈希。
新增 reparse 操作，从归档重建队列、校验 HTML 哈希并运行当前 parser，不调用 HTTP。
验证：123 个测试通过，覆盖内容历史与去重、重复内容再次成为最新版本、损坏/缺失归档、
空检查点从归档离线启动及 HTTP/发现调用禁止。

## C5

改动：按规范路径锁定数据库、正式输出、进度输出与日志；不同数据库共享输出时立即拒绝启动。
单课程和目录文件输出同样加锁，数据路径不得覆盖锁文件。
验证：125 个测试通过，覆盖另一数据库争用输出时在 I/O 前停止、锁文件路径冲突及既有锁释放回归。

## C6

改动：复用已独立的 URL 规则模块，新增 Course TypedDict 和运行时校验器。
解析、应用编排及持久化边界校验固定字段、值类型、必需文本和 UTM code/URL/campus 一致性。
验证：127 个测试通过，覆盖非法结构、未知字段、类型、必需文本、身份错误及复制隔离。
现有 2,491 门课程均通过新契约；持久化与崩溃测试使用合法课程样本。

## C7

改动：统一编号迁移框架，使用 SQLite user_version、application_id 和迁移历史表。
课程库、HTTP 缓存及原始 HTML 索引均采用事务化迁移；拒绝较新版本、未知旧表和错误组件数据库。
数据库初始化失败关闭连接，运行元数据记录 schema 版本。
验证：130 个测试通过，覆盖 DDL/版本回滚、重复打开幂等性、较新版本拒绝、组件隔离与旧数据保留。
